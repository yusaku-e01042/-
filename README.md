# かんたん株ポートフォリオ（PayPay証券メイン）

PayPay証券で積立している米国株・日本株を、**スマホでパッと開いてリアルタイムに確認**するための Web アプリです。
SBI証券の分もサブとして登録でき、タブで「PayPay証券 / すべて / SBI証券」を切り替えられます（初期表示は PayPay証券）。

## できること

- **評価額・評価損益・前日比**を自動更新（初期設定は30秒ごと。設定で15秒〜5分に変更可）
- 米国株はドル建て株価 × ドル円レートで**円に換算**
- PayPay証券の**端数株（0.123456株など）**にそのまま対応
- **積立設定**（毎日／毎週／毎月・金額）→ 毎月の積立額の合計と、将来シミュレーション
- 積立が約定したら「＋ 買付を記録」で数量と投資額を足していくだけ
- **目標まで**：目標金額（例: 100万円）までの達成率、今のペースで届く時期、◯年で届くのに必要な毎月の積立額
- **来月の積立プラン**：毎月の予算（例: 4,000円）と「目標の割合」を決めると、目標に近づく買い方（銘柄ごとの金額）を自動で計算
- **税金の目安**：今売ったら税金（20.315%）がいくらか、NISA で非課税になっている額
- 証券会社ごと・銘柄ごとの資産配分
- ダークモード対応、ホーム画面に追加するとアプリのように使えます

## 使い始め方

### 1. 公開する（GitHub Pages・無料）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを公開したいもの（例: `main`）、フォルダを `/ (root)` にして **Save**
3. 数分後に表示される URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開く
4. iPhone なら Safari の共有ボタン →「ホーム画面に追加」、Android なら Chrome のメニュー →「ホーム画面に追加」

> パソコンで試すだけなら `python3 -m http.server` をこのフォルダで実行し、`http://localhost:8000` を開いてもOKです。

### 2. 銘柄を登録する

PayPay証券アプリの「保有資産」画面を見ながら「＋ 銘柄を追加」で入力します。

| 項目 | 入れるもの |
|---|---|
| ティッカー / 証券コード | 米国株: `AAPL` `VOO` など／日本株: `7203` など（自動で `7203.T` になります） |
| 保有数量 | アプリに出ている保有数量（端数そのまま） |
| 平均取得単価（任意） | アプリに平均取得単価しか出ていない場合に入力 → 投資金額を自動計算 |
| 投資金額の合計（円） | これまでに買った合計額（取得金額）。過去の積立分も全部含めた合計 |

> これまで積み立ててきた分は、1回ずつ入れる必要はありません。今の「保有数量」と「合計（または平均取得単価）」を入れるだけでOKです。
| 積立設定 | PayPay証券で設定している頻度と1回の金額 |

投資信託は「種類：投資信託」を選び、基準価額（1万口あたり）を手入力します。
「値動きの連動先」を選ぶと、入力した基準価額をもとに連動先の値動きで**今の価値をリアルタイムに推定**します。

| ファンドの例 | 連動先 |
|---|---|
| 三菱UFJ純金ファンド（ファインゴールド） | 金（純金上場信託 1540） |
| S&P500連動の投信（eMAXIS Slim 米国株式など） | S&P500（VOO） |
| 全世界株の投信（オルカンなど） | 全世界株（VT） |

ときどき実際の基準価額を入れ直すと、推定のずれがリセットされます。

### 3. 積立が約定したら

その銘柄の「＋ 買付を記録」→ 金額と増えた数量を入れるだけで、保有数量と投資額が更新されます。

## データの保存場所（プライバシー）

- 保有データは **その端末のブラウザの中だけ** に保存されます。サーバーやGitHubには送られません。
- 機種変更や別の端末で見るときは、**設定 →「書き出す」→ もう一方で「読み込む」** で移せます。
- ブラウザの履歴・データを削除すると消えるので、ときどき書き出しておくと安心です。

## 株価データについて

- Yahoo! Finance の公開データを取得しています（米国株はほぼリアルタイム、**日本株は約20分遅れ**の場合あり）。
- ブラウザの制限で直接取れない場合は、公開の中継サービスを順番に試します。
- 取得が不安定なときは次のどちらかで安定します：
  - **Finnhub APIキー**（無料）を設定に入れる → 米国株が安定
  - `worker/cloudflare-worker.js` を Cloudflare Workers（無料）にデプロイし、そのURLを設定の「自前の中継URL」に入れる → 米国株・日本株とも安定
- 表示される評価額は「市場価格 × 為替」で計算した目安です。PayPay証券アプリの表示（為替コスト・取引コスト込み）とは少しずれます。

## PayPay証券とSBI証券、税金のメモ

- 株の利益にかかる税金は **どの証券会社でも同じ 20.315%**（特定口座・一般口座）です。
- 税金を減らせるのは証券会社ではなく **NISA口座かどうか**。NISA の利益は非課税です。
  このアプリの「NISAで非課税になった額」で、NISA の効果を確認できます。
- 証券会社で違うのは主に **手数料・為替コスト**です。PayPay証券は手数料が「スプレッド（売買価格に上乗せ）」方式なので、
  気になる場合はアプリの約定履歴で確認してください。
- NISA口座は1人1社しか持てません。PayPay証券をメインにするなら、NISA口座を PayPay証券に移す（金融機関変更）と
  積立も NISA で非課税にできます（手続きの詳細は各社の案内を確認してください）。
